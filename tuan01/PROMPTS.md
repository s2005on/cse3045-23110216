\# PROMPTS - HW1



\## Công cụ AI



ChatGPT



\## Nội dung đã hỏi AI



Tôi sử dụng ChatGPT để được hướng dẫn từng bước thực hiện HW1,

bao gồm:



\- Thiết lập cấu trúc repository Git.

\- Gợi ý bài toán quản lý điểm sinh viên.

\- Gợi ý cách refactor code sang Python hiện đại.

\- Hướng dẫn sử dụng type hints, dataclass, pathlib và f-string.

\- Hướng dẫn chạy ruff và mypy.

\- Hướng dẫn quy trình commit, push và Pull Request.



\## Phần AI hỗ trợ



AI hỗ trợ đề xuất cấu trúc chương trình và ví dụ code refactor.



\## Phần tôi thực hiện



\- Tự tạo và quản lý repository GitHub.

\- Tự thiết lập môi trường uv.

\- Tự tạo và chạy chương trình trên máy.

\- Tự kiểm tra kết quả chương trình.

\- Tự chạy ruff format, ruff check và mypy.

\- Kiểm tra và hiểu các thay đổi giữa phiên bản cũ và phiên bản refactor.



\## Những gì tôi học được



Tôi hiểu cách sử dụng:



\- Git branch và Pull Request.

\- Type hints trong Python.

\- dataclass để biểu diễn dữ liệu.

\- pathlib để xử lý đường dẫn.

\- f-string để định dạng chuỗi.

\- ruff để format/lint code.

\- mypy để kiểm tra kiểu dữ liệu.
